Шаблон эмулятора для работы с Kafka.

В данном шаблоне используется зависимость spring-kafka
Версия spring-boot-starter-parent 2.6.4, соответственно сборщик подберет версии зависимостей, которые будут совместимы между собой 

Проект состоит из 4 папок:
1. config - настраиваются конфигурации нужных бинов
2. kafka - настраиваются классы и объекты для подключения и работы с kafka
3. model - представлены объекты, с которыми приложение будет работать
4. service - классы, в которых реализована логика работы приложения

Начинать работу нужно с настройки kafka. В папке kafka->config-> настройка параметров,  
которые определены в конфигурационном файле приложения application.yml.
В каждом классе объявлены поля экземпляров, которые spring инициализирует при старте приложения 
из application.yml.

В папке kafka->config создаются объекты, которые будут работать с kafka. 
Здесь же настраиваются различные свойства для работы этих объектов.

В папке kafka->consumer и kafka->producer создаются классы для вычитывания 
и отправки сообщений kafka.

В папке model объекты, в которые будут преобразовываться полученные сообщения
для дальнейшей обработки и отправки.

В папке service класс, в котором может быть реализована логика обработки полученных сообщений.

При вычитывании сообщения из kafka в классе KafkaConsumer, мы вызываем асинхронный 
метод handleMessage в классе ReceiveMessageService, который может содержать логику 
обработки сообщения. Параметры для реализации асинхронной обработки заданы в классе
AppConfig в методе taskExecutor, который создает бин ThreadPoolTaskExecutor, чтобы метод handleMessage, 
помеченный аннотацией @Async("taskExecutor"), выполнился в отдельном потоке.
